## Порядок работы

1. Решение принято — появляется файл `NNNN-короткое-имя.md` со статусом «Предложено».
2. Команда согласна — статус меняется на «Принято», строка добавляется в таблицу выше.
3. Решение устарело — пишется новая запись, в старой статус «Заменено записью NNNN».
4. `docs/traceability.md` ссылается на номер записи из колонки «Решение».
