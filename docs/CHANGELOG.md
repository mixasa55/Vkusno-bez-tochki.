# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Добавлено

- Постановка проблемы, персоны (2), путь пользователя, MVP и область вне охвата (ЛР 1А)
- Карта пути клиента для обеих персон
- Карта пользовательских историй с выделенным MVP
- Дорожная карта и план семестра
- Определения готовности и завершённости, ритм команды
- FR-01…FR-05 с INVEST и четырьмя критериями приемки, NFR-01…NFR-05, ограничения C-01…C-05, приоритизация MoSCoW, конфликты и предположения (ЛР 2А)
- Единый язык: 14 терминов, запрещённые слова, проверка «на три совпадения» (ЛР 2Б)
- Событийное бурление: 14 событий, 7 событий отказа, 4 расхождения, 3 вопроса без ответа, связи контекстов (ЛР 2Б)
- Агрегаты «Рецепт» и «Магазин»: 10 инвариантов, границы, что инвариантом не является (ЛР 2Б)
- ADR-0004 «Без аутентификации в MVP», ADR-0005 «Снимок цен вместо синхронного запроса», указатель решений по темам (ЛР 2В)
- Обзор архитектуры: границы, таблица решений, NFR → тактика → место, STRIDE, осознанно не сделанное (ЛР 2В)
- Диаграммы C4: контекст (3 роли, 3 внешние системы), контейнеры (4 контейнера с версиями), модель данных (8 сущностей) (ЛР 2Г)
- Последовательность поиска с тремя ветвями отказа, привязанными к критериям приемки (ЛР 2Г)
- Каталог операций API для FR-01…FR-05 с кодами ответов и ролями (ЛР 2Г)
- Руководство по чтению архитектуры: файл — читатель — вопрос, соглашение нотации, результат пяти сверок (ЛР 2Г)

### Изменено

- `FR-02` переформулирован: КБЖУ показывается на порцию, справочные значения — на 100 г
- `FR-05`: вместо оценки рецепта — пошаговая инструкция (оценки нет в объёме)
- `NFR-05` уточнён: 4 из 5 участников находят рецепт за одну попытку ввода
- Матрица прослеживаемости заполнена: колонка «Решение» ссылается на ADR и диаграммы, добавлены обратные проверки в обе стороны
- В модели данных КБЖУ разнесено по нутриентам на 100 г, добавлены `COOKING_STEP`, `PRICE_SNAPSHOT`, `STORE_PRODUCT`, `created_at`/`updated_at` в `timestamptz`
- Язык серверной части зафиксирован как Python 3.14
