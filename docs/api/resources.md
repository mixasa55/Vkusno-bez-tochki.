# Ресурсы API (ЛР 2Г)

Контракт формируется из типов `pydantic` ([ADR-0002](../adr/0002-backend-language.md)): описание OpenAPI каркас отдаёт сам, этот документ — источник согласования с фронтендом до написания кода.

Соглашения:

- Префикс версии: `/api/v1`.
- Тело и ответы — JSON в кодировке UTF-8, имена полей в `snake_case`.
- Ошибки валидации — единый формат `{"error": {"code": "...", "fields": {"имя_поля": "сообщение"}}}` с кодом 422 (`AC-01.4`, `AC-02.4`, `AC-04.4`).
- Аутентификации нет ([ADR-0004](../adr/0004-authentication-strategy.md)), поэтому во всех операциях роль — **Аноним**; 401 и 403 контрактом не предусмотрены.
- КБЖУ в ответах — на порцию (`PortionNutrition`), вычисляется на чтении; справочные значения на 100 г наружу не отдаём.

## Каталог операций

| Требование | Операция | Роль | Коды | Критерии |
|---|---|---|---|---|
| `FR-01` | `POST /api/v1/recipes/search` | Аноним | 200, 422 | `AC-01.1`, `AC-01.2`, `AC-01.3`, `AC-01.4` |
| `FR-02` | `GET /api/v1/recipes/{id}` | Аноним | 200, 404, 422 | `AC-02.1`, `AC-02.2` |
| `FR-03` | `GET /api/v1/prices` | Аноним | 200, 422 | `AC-03.1`, `AC-03.2`, `AC-03.3`, `AC-03.4` |
| `FR-04` | `POST /api/v1/recipes/search` (параметры фильтра) | Аноним | 200, 422 | `AC-04.1`, `AC-04.2`, `AC-04.3`, `AC-04.4` |
| `FR-05` | `GET /api/v1/recipes/{id}/steps` | Аноним | 200, 404, 422 | `AC-05.1`, `AC-05.2`, `AC-05.3`, `AC-05.4` |
| `NFR-03` | `GET /api/v1/health` | Оператор | 200, 503 | проверка готовности после перезапуска |

`FR-04` не вводит отдельный ресурс: фильтр — часть того же подбора, иначе фронтенду пришлось бы объединять два ответа, а `NFR-01` считался бы по двум запросам.

## FR-01 · FR-04 — поиск рецептов

`POST /api/v1/recipes/search`

Запрос:

```json
{
  "ingredients": ["курица", "рис"],
  "max_kcal": 500,
  "min_protein_g": 30
}
```

- `ingredients` — от 1 до 3 значений, каждое до 40 символов. Один ингредиент допустим, но добавляет `warning` (`AC-01.3`).
- `max_kcal`, `min_protein_g` — положительные целые, оба необязательны (`FR-04`). Текст вместо числа или отрицательное значение → 422 (`AC-02.4`, `AC-04.4`).

Ответ 200:

```json
{
  "items": [
    {
      "id": "0f1f...-1",
      "title": "Курица с рисом",
      "servings": 2,
      "cooking_time_min": 35,
      "match_score": 0.67,
      "nutrition_per_portion": { "kcal": 480, "protein_g": 34, "fat_g": 12, "carbs_g": 51 },
      "missing_ingredients": [
        { "id": "0f1f...-9", "name": "помидоры", "amount_g": 100, "price": { "value": 189.9, "currency": "RUB", "collected_at": "2026-11-07T06:00:00Z" } }
      ],
      "prices_available": true
    }
  ],
  "total": 1,
  "warning": null,
  "suggest_reset_filters": false
}
```

Поведение по критериям:

| Код | Случай | Что в ответе |
|---|---|---|
| 200 | Рецепты найдены | `items` с КБЖУ порции и совпадением (`AC-01.1`) |
| 200 | Ничего не найдено | `items: []`, `warning: "NO_MATCH"` с подсказкой убрать фильтр (`AC-01.2`) |
| 200 | Фильтр сузил выборку до нуля | `items: []`, `suggest_reset_filters: true` (`AC-04.2`) |
| 200 | Рецепт ровно на границе 500 ккал | входит в `items` (`AC-04.3`) |
| 200 | Снимок цен просрочен | `prices_available: false`, `price: null` (`AC-03.2`) |
| 422 | Символы вместо ингредиентов, текст в числе | `error.fields` с указанием поля (`AC-01.4`, `AC-04.4`) |

## FR-02 · FR-03 — карточка рецепта и цены

`GET /api/v1/recipes/{id}` — состав, КБЖУ порции, сколько порций, время приготовления.

- 200 — карточка; если справочных данных КБЖУ нет, поле `nutrition_per_portion: null`, а не нули (`AC-02.2`).
- 404 — рецепта с таким `id` нет (`AC-05.4`).
- 422 — `id` не является UUID.

`GET /api/v1/prices?ingredients=0f1f...-9,0f1f...-8&lat=55.75&lon=37.62`

| Параметр | Обязателен | Смысл |
|---|---|---|
| `ingredients` | да | список `ingredient_id` через запятую (ссылка по ID, как в агрегатах) |
| `lat`, `lon` | нет | геолокация пользователя; без них берутся магазины по умолчанию (`AC-03.4`) |

Ответ 200:

```json
{
  "snapshot_collected_at": "2026-11-07T06:00:00Z",
  "store": { "id": "0f1f...-3", "name": "Магнит", "distance_km": 1.4 },
  "items": [
    { "ingredient_id": "0f1f...-9", "name": "помидоры", "value": 189.9, "currency": "RUB" }
  ],
  "total": { "value": 189.9, "currency": "RUB" }
}
```

- `store.distance_km` считается по координатам, радиус поиска 2 км (`AC-03.3`).
- Валидного снимка нет → `items: []`, `snapshot_collected_at: null` (`AC-03.2`).
- 422 — некорректный `lat`/`lon` вне допустимого диапазона (инвариант И-8).

## FR-05 — шаги приготовления

`GET /api/v1/recipes/{id}/steps`

```json
{
  "recipe_id": "0f1f...-1",
  "steps": [
    { "position": 1, "instruction": "Нарежьте курицу и обжарьте 10 минут." },
    { "position": 2, "instruction": "Отварите рис, соедините с курицей." }
  ]
}
```

| Код | Случай | Что в ответе |
|---|---|---|
| 200 | Шаги есть | массив в порядке `position` (`AC-05.1`) |
| 200 | Шагов нет | `steps: []`, `warning: "INSTRUCTION_EMPTY"` — фронтенд показывает состав (`AC-05.2`) |
| 200 | Один шаг | массив из одного элемента, нумерация не требуется (`AC-05.3`) |
| 404 | Рецепта нет | `error.code: "RECIPE_NOT_FOUND"` (`AC-05.4`) |

## Ошибки и коды

| Код | Когда | Требование |
|---|---|---|
| 200 | Успех, включая пустую выборку | `FR-01`, `FR-04` |
| 404 | Несуществующий ресурс по `id` | `AC-05.4` |
| 422 | Данные не прошли проверку модели | `AC-01.4`, `AC-02.4`, `AC-04.4` |
| 500 | Неизвестная ошибка сервиса | `NFR-02` — событие пишется в журнал с `request_id` |
| 503 | База недоступна, готовность не подтверждена | `NFR-03` |

Отказ внешних источников не порождает 5xx: цены и КБЖУ деградируют до 200 с пустыми полями ([ADR-0005](../adr/0005-price-snapshot-cache.md)).
