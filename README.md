# Vkusno bez tochki.

Сервис подбора рецепта по 2–3 имеющимся ингредиентам: рецепты, КБЖУ, цены на недостающие продукты в магазинах поблизости.

- **Команда**: Михаил (@mixasa55), <Имя друга> (@<логин>)
- **Курс**: Технологии разработки программных систем, ОмГТУ, 09.03.01
- **Предметная область**: рецепты, ингредиенты, магазины и цены, КБЖУ, рекомендации

## О проекте

Пользователь вводит 2–3 продукта, которые у него есть. Сервис показывает рецепты, где они — основные ингредиенты, с КБЖУ на порцию, списком недостающих продуктов и ценой в ближайших магазинах. Персоны и сценарии — в [docs/requirements.md](docs/requirements.md).

## Как получить локально

git clone git@github.com:mixasa55/Vkusno-bez-tochki..git
cd Vkusno-bez-tochki.

Кода пока нет — появится в модуле 07.

## Как внести изменение

1. Создать ветку от `main`: `git switch -c feat/short-name`
2. Внести изменения, закоммитить по формату из [CONTRIBUTING.md](CONTRIBUTING.md)
3. Отправить ветку и открыть Pull Request
4. Дождаться ревью второго участника и зелёного конвейера
5. Слить squash-merge, ветку удалить

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).
